O **Conecta Feira** é um Marketplace Digital focado em conectar pequenos produtores rurais diretamente aos consumidores finais. O objetivo é eliminar intermediários, aumentar o lucro do produtor e garantir alimentos frescos na mesa do cliente.

![Status do Projeto](https://img.shields.io/badge/Status-Concluído-brightgreen)
![Tech Stack](https://img.shields.io/badge/Tech-React%20%7C%20Supabase%20%7C%20TypeScript-blue)

## 🚀 Funcionalidades

### Para o Cliente (Consumidor)
- 🔍 **Busca Inteligente:** Pesquisa global por produtos ou categorias (ex: "Tomate", "Queijo").
- 🛒 **Carrinho de Compras:** Adição e remoção de itens com cálculo automático de subtotal.
- 📱 **Checkout via WhatsApp:** O pedido é formatado e enviado diretamente para o WhatsApp do produtor.
- 📍 **Vitrine Virtual:** Visualização dos produtores da região.

### Para o Produtor (Admin)
- 🔐 **Autenticação Segura:** Login e Cadastro automático.
- 📦 **Gestão de Estoque:** CRUD completo (Criar, Ler, Atualizar, Deletar) de produtos.
- 📸 **Upload Otimizado:** Compressão automática de imagens para economizar dados.
- ✏️ **Perfil:** Edição de dados da banca e contato.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React.js + Vite + TypeScript
- **Backend & Banco de Dados:** Supabase (PostgreSQL + Auth + Storage)
- **Estilização:** CSS Moderno (Variáveis CSS, Design Responsivo)
- **Deploy:** Vercel
